# E-Commerce Sales Performance Dashboard 📊

## Project Overview
This project analyses a simulated e-commerce dataset containing 500 orders using Microsoft Excel. The goal is to understand sales performance, customer purchasing patterns, product performance, returns and delivery operations through an interactive dashboard.

## Tools & Technologies
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Formulas
- Power Query
- Slicers
- Data Cleaning and Analysis

## Dataset
The dataset contains 500 orders with information about:
- Orders and customers
- Products and categories
- Regions and sales channels
- Discounts, revenue and costs
- Profit and returns
- Shipping and delivery information
- Payment methods

## Dashboard Features
- Total Orders
- Net Revenue
- Realized Profit
- Average Order Value
- Regional Revenue Analysis
- Category-wise Revenue Analysis
- Monthly Revenue Trends
- Top 10 Products Analysis
- All Products Revenue Analysis
- Returns Analysis
- Delivery Analysis
- Payment Method Analysis
- Sales Channel Analysis

## Key Business Insights
1. West recorded the highest net revenue at ₹4,93,349.50.
2. Air Fryer was the highest-revenue product at ₹2,47,505.
3. The overall order return rate was 7.4%.
4. 493 out of 500 orders were delivered.
5. UPI was the most-used payment method, with 152 orders.

## Interactive Features
The dashboard uses Excel slicers to dynamically filter and explore sales performance across different dimensions.
